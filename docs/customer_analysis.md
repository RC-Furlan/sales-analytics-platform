# Análise de Clientes

## Objetivo

Identificar os clientes que mais geraram receita para a empresa.

## Fonte dos Dados

- Sales.Customer
- Person.Person
- Sales.SalesOrderHeader

## Métrica

Receita Total = SUM(TotalDue)

## Critério

Ordenação decrescente da receita e seleção dos 10 maiores clientes.
