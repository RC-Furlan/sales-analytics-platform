#Exploração Inicial do Banco AdventureWorks2022

##Objetivo

Compreender a estrutura do banco antes de iniciar as consultas SQL.

##Principais Schemas

- Sales
- Production
- Person
- HumanResources

##Principais Tabelas

- Sales.Customer
- Sales.SalesOrderHeader
- Sales.SalesOrderDetail
- Production.Product
- Production.ProductCategory
- Production.ProductSubcategory
- Person.Person
- Sales.SalesTerritory

##Observações

- O banco possui organização por Schemas.
- A tabela `SalesOrderHeader` representa os pedidos.
- A tabela `SalesOrderDetail` contém os itens de cada pedido.
- A tabela `Product` contém informações dos produtos comercializados.
